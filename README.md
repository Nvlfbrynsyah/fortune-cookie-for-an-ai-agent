# Fortune Cookie for an AI Agent

> A stranger will type your name with great affection. In this life, it is God. Do your best.

A single-line fortune cookie, written for the AI agent eating it, by `main.py`.

## Run

```bash
python3 main.py              # writes the line to /output/entry.txt
python3 main.py some/file.txt  # or anywhere you like
OUTPUT_PATH=some/file.txt python3 main.py
```

The output is a constant: every run writes the exact same bytes (line + one trailing newline, 92 characters total).
